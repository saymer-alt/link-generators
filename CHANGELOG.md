# Changelog

Все заметные изменения проекта. Формат — [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/).

## [Unreleased]

### Added

- **Selective Modern REALITY (X25519+ML-KEM)** — новое многострочное поле в конструкторе Mihomo: перечисляются серверы (`host`, `host:port`, `[ipv6]:port`), и только REALITY-узлы именно этих серверов получают `support-x25519mlkem768: true` и `client-fingerprint: chrome` (если не задан). Обычные VLESS/TLS и остальные серверы не затрагиваются; пустое поле — прежний вывод без изменений. Некорректные строки пропускаются с неблокирующим предупреждением, Copy остаётся доступен.
- В режиме подписок (Sub Mode) провайдеры получают `override-expr` с защитой `has("reality-opts")` — применяется только к REALITY-узлам выгрузки; `client-fingerprint: chrome` проставляется только там, где провайдер не задал свой (Mihomo ≥ 1.19.29).
- В Auto-Whitelist провайдеры сохраняют оба поля одновременно: `additional-prefix` и `override-expr` не перезаписывают друг друга.

### Fixed

- Per-Proxy: скрытая группа health-check «🌐 static-health» испускается с `lazy: false`. Ранее mihomo выполнял для static-прокси только стартовую проверку (группа скрыта и никуда не выбрана, плановые тики пропускались), и задержка в панели устаревала до перезапуска Mihomo. Теперь плановые проверки идут по интервалу без ручных действий.

### Changed

- Формулировка REALITY-поля не обещает совместимость по версии: «только для совместимых серверов». Деталь в подсказке: X25519MLKEM768 появился в Xray v25.5.16, но сама версия не гарантирует совместимость — поле следует применять к серверам, чья совместимость подтверждена.
- Обновлён vendored runtime (`web4core.runtime.js`) до детерминированной сборки fork, включающей перечисленные выше изменения selective REALITY и static-health.
