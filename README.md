# WARP & Mihomo Unified Generator

Мощный оффлайн-генератор ссылок и конфигураций для обхода глубокого анализа трафика (DPI) и сборки сложных цепочек проксирования в Mihomo. 

Инструмент объединяет в себе генерацию безопасных `masque://` ссылок, парсинг логов утилиты `warpscout` и автоматическую сборку готовых `config.yaml` для роутеров и серверов.

🌐 **Live Demo:** [saymer-alt.github.io/link-generators](https://saymer-alt.github.io/link-generators/)

---

## ⚡ Ключевые возможности

*   **Умная генерация MASQUE:** Создание ссылок `masque://` (QUIC и HTTP/2) с использованием взвешенного рандома безопасных портов (443, 8443, 4443, 8095) и анти-корреляцией IP-адресов.
*   **Warpscout Parser:** Прямая конвертация сырых текстовых отчетов утилиты [warpscout](https://github.com/vernette/warpscout) и файлов `warpscout-account.json` в готовые к использованию YAML-блоки для Mihomo. Автоматическое определение протоколов (AWG, MASQUE) по портам.
*   **Mihomo Config Builder:** Сборка полноценных конфигураций из разрозненных ссылок (VLESS, VMess, Trojan, SS, Hysteria2, TUIC, MASQUE, Mieru, TrustTunnel) и файлов WireGuard/AmneziaWG (`.conf`, `.awg`).
*   **WARP-in-WARP (Цепочки):** Автоматическая генерация вложенных туннелей (матрешек) через параметр `dialer-proxy` для обхода геоблокировок и получения правильного региона (SEEN AS).

## 📖 Как этим пользоваться?

Генератор разбит на три логические вкладки, закрывающие разные сценарии.

### Сценарий 1: Быстрая генерация MASQUE-ссылок
Если у вас есть YAML-конфиг от Telegram-бота или файл `warpscout-account.json`:
1. Откройте вкладку **⚡ WARP MASQUE Links**.
2. Вставьте текст конфига или JSON в верхнее окно и нажмите «Распарсить» (ключи и IP заполнятся автоматически).
3. Укажите нужное количество пар и нажмите «Сгенерировать ссылки». 
4. Полученные ссылки можно сразу отправить в Mihomo Builder одной кнопкой.

### Сценарий 2: Конвертация логов Warpscout в YAML
Если вы просканировали сеть утилитой `warpscout` и получили список из десятков эндпоинтов:
1. Откройте вкладку **📝 Warpscout Parser**.
2. Вставьте содержимое файла `warpscout-account.json` в первое поле.
3. Вставьте сырой текст отчета (лог сканирования) во второе поле.
4. Выберите определение протокола (Автоматически) и нажмите «Сгенерировать Proxies». На выходе вы получите чистый массив `proxies:` со всеми рабочими адресами.

### Сценарий 3: Сборка цепочки WARP-in-WARP (Обход геоблокировок)
Чтобы сайты видели ваш зарубежный IP-адрес, а провайдер не мог заблокировать туннель:
1. Подготовьте внешний пробивающий туннель: выгрузите через `warpscout` конфиг AmneziaWG зарубежного узла (например, FRA) в виде `.conf` файла.
2. Подготовьте внутренний туннель: сгенерируйте `masque://` профили во вкладках генератора.
3. Перейдите во вкладку **⚙️ Mihomo Config Builder**.
4. Вставьте ссылки MASQUE в верхнее текстовое поле.
5. Нажмите кнопку **«📂 Загрузить .conf / .awg»** и выберите ваш зарубежный `.conf` файл.
6. Отметьте чекбокс **«🔗 WARP-in-WARP»** и нажмите **«Build Config»**.

Скрипт автоматически свяжет туннели: весь MASQUE-трафик будет завернут внутрь стабильного внешнего соединения AmneziaWG.
