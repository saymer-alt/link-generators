Ключевые контракты (не нарушать молча)

  • masque:// формат и anti-DPI стратегия — описаны в AGENTS.md (корень).
  • Версионный контракт Mihomo: minimum 1.19.31, recommended/current 1.19.32; MIPS stack требует >= 1.19.31 (warning в валидаторе, не блокер); gVisor — fallback; исторические минимумы функций (AWG 3.1 >= 1.19.30, DPR >= 1.19.27) — отдельно.
  • Модель профилей развёртывания: router (по умолчанию) / vps-local / vps-gateway; устаревшие идентификаторы generic/vps не используются как пользовательская модель.
  • Flat GLOBAL fallback в Auto-Whitelist; nested-группы запрещены (#2588).
  • DDP (домен-детект) — инвариант профиля vps-gateway: tun.dns-hijack + пассивный sniffer + store-fake-ip: true при включённом fake-ip DNS; патчер установщика gateway сохраняет значение (PR #33 amnezia-mihomo-gateway, merged).
  • web4core.runtime.js — generated; меняется только через fork saymer-alt/web4core@link-generators + workflow.
