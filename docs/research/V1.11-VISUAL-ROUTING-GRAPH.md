# Visual Routing Graph (#125→#177, v1.11 EVENING-03)

Дата: 2026-10-08. Статус: **DONE** (графический SVG-рендер + focus-режим + тесты).
Базис: main после PHASE A (EVENING-03).

## 1. Каноническая модель

Используется существующий `cdgBuildGraph(doc)` (RD-CORE) — без второго парсера. Граф строится только из generated config: узлы (rule, rule-provider, proxy-group, proxy, proxy-provider, dns-policy, dns-entry, dns-config, builtin, unresolved) и рёбра (routes-to, uses, dialed-through, resolves-via). Никаких дополнительных связей не дорисовывается.

## 2. Ядро раскладки (VRG-CORE)

`vrgBuildView(graph, opts)` — pure:
- слоёная раскладка (longest-path layering через Kahn);
- циклы — fallback последовательные уровни + `cyclePresent` маркер;
- усечение `maxNodes` (дефолт 60) — первые N в порядке вставки, `hiddenNodes`/`hiddenEdges` считаются явно;
- focus-режим — BFS в обе стороны от выбранного узла, лимит тот же.

## 3. UI-контракт

Панель «Visual Routing Graph» внутри Routing Intelligence (Builder snapshot) и Config Studio (csCurrentDoc после анализа):
- SVG без внешних зависимостей (createElementNS, textContent — XSS-safe);
- узлы: rect + kind-метка + label (truncated 28 символов);
- рёбра: линии со arrow-marker;
- focus select (optgroup по типам) + сброс;
- текстовая альтернатива (screen reader);
- STALE как в остальных Routing Intelligence панелях;
- статусная строка (узлы/связи/скрытые/циклы/STALE);
- клик/keyboard focus на узле — aria-label.

## 4. Обработка динамических групп

Динамические группы (select/url-test/fallback/load-balance) показывают **состав** (рёбра `uses`), но никогда — гарантированно выбранный участник. Поле `selected` в VRG отсутствует.

## 5. Ограничения

- Усечение — первые N в порядке вставки (не по «важности»); фокус — способ просмотра конкретного подграфа.
- Не интерактивный редактор, не drag-and-drop.
- Невидимые связи НЕ создают ложного впечатления завершённости — счётчик hidden показывается явно.

## 6. Privacy / security

Все подписи через `textContent` (XSS-safe). Никаких секретов в графе — /proxies и credentials в CDG-модель не входят. document-aware redaction Config Studio применяется к подписям через общий `csRedactText` pipeline.

- `tests/config-studio-browser.cjs` — Config Studio VRG + network diagnostics + what-if interplay
- Полная батарея 40+ сюит green.
