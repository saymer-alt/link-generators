## Remaining limitations and safe workarounds

| Limitation | User consequence | Safe workaround |
| --- | --- | --- |
| Sub OFF original URLs | Expanded nodes do not retain original subscription URLs. | Save project before expansion; retain original sources privately. |
| Direct URI emitter | Arbitrary parsed proxy nodes cannot all be recreated as input links. | Keep source YAML / Studio editor or original project; review unsupported report. |
| Per-Proxy listeners | Reverse cannot recreate per-node listener intent exactly. | Preserve original YAML and configure inbound mapping explicitly; no parity claim. |
| Raw keepalive ranges | Mihomo cannot express a source range as equivalent behaviour; optional 25-second compatibility policy differs. | Keep original profile/project; select the documented compatibility option deliberately. |
| Arbitrary YAML | Unmodelled fields are not silently merged into a fresh Builder output. | Keep source YAML, use Studio/editor and review Preview before Confirm. |
| AWL missing fallback URL | YAML may lack source information required to restore a valid fallback input. | Restore project/original fallback source; do not invent a URL. |
| Tiered custom health multi-URL | Reverse reports CONFLICT rather than silently flattening. | Continue with project or original YAML. |
| Runtime routing | Group choice, provider contents and actual route are not statically known. | Inspect an authorized controller and measure traffic separately. |
| CORS / real subscriptions | Offline mocks do not prove a remote server response or browser CORS. | Owner tests a private non-production source and checks preview/errors. |
| Real Keenetic/VPS/handshake | This audit did not access owner devices or alter their routing. | Follow the staged owner procedure below; production acceptance remains pending. |
