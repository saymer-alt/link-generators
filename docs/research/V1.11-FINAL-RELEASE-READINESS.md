## Матрица воспроизводимой приёмки

Полная локальная регрессия: **55 CJS suites PASS**, parity отдельно **10/10** против исходного main; harness **31/31**, secret scan PASS. Linux runtime labs и две manual environment suites не выдаются за локальный результат. Изолированные Linux jobs и обе pinned версии Mihomo должны быть зелёными на окончательных опубликованных heads. Прежние тесты сохранены.

Synthetic fieldtest: **49 сценариев, 29 positive +20 ожидаемых negative, 0 неожиданных ошибок**, повторены на main и синхронизированном кандидате. По 149 real-core checks: 141 ожидаемый ACCEPT и 8 REJECT. WEB VALID, core acceptance, поддерживаемая Reverse PARITY, явные потери и UNKNOWN не смешиваются. Порт 70000 отклонён web transport contract даже там, где upstream принимает YAML; это не объявляется core rejection.

Браузеры: Chromium 140.0.7339.16, Edge 154.0.4258.62, Firefox 141.0, WebKit 26.0 — **PASS**, по 72 раскладки (6 разделов ×12 ширин): 320/360/375/390/412/480/768/1024/1366/1440/1920/2560. Проверены Builder/WG, изменённый dialer, Studio/VRG/DNS при наличии, Reverse Preview, YAML Editor, Physical Topology. Настоящие клики: Save/reload/Load Cancel/Confirm, изменения, Build, Studio, Reverse Cancel/Confirm/Undo и графы. Runner сохраняет результаты каждого браузера; недоступный браузер получает NOT RUN.

Mobile: viewport/overflow и видимые control targets PASS; реальных телефонов/touch hardware не было. Keyboard: Tab/Shift+Tab, видимый focus и Enter/Space disclosure PASS. Accessibility: отдельные контролы, **не полный WCAG-аудит**, не сертификация screen reader/contrast. Минимальный проверенный hitbox — 24 px, не гарантия комфортных 44 px.

Security: прежние 49 core stress groups и 59 browser checks PASS. Проверены bounded YAML/JSON/aliases/depth, prototype pollution, injection, document-aware redaction, stale operations и import controls. DNS URL credentials/path/query tokens скрыты в диагностике; функциональные исходники/YAML/проекты намеренно сохраняют секреты для восстановления. ## Семантика DNS (#207)

Проверены disabled/missing `dns.enable`; безусловные структурные требования respect-rules/proxy-server-nameserver; transport отдельно от proxy; fragments и resolver arrays; nameserver-policy; first-match/PASS; direct/global mode. Opaque RULE-SET/GEOSITE и fake-IP/IP-сравнения остаются UNKNOWN, explicit proxy не получает ложный bypass. Повторный Parse заменяет snapshot, не меняя исходник/Builder; Reverse не выдумывает отсутствующие DNS policies.

Первичные контракты: [Mihomo1.19.32 mode/match](https://github.com/MetaCubeX/mihomo/blob/v1.19.32/tunnel/tunnel.go), [DNS dialer](https://github.com/MetaCubeX/mihomo/blob/v1.19.32/tunnel/dns_dialer.go), [defaults/validation](https://github.com/MetaCubeX/mihomo/blob/v1.19.32/config/config.go). Research кандидата содержит ссылки на обе pinned версии. Это семантика реализации, не измерение трафика.

## Ограничения и безопасные обходные пути

| Ограничение | Последствие | Обходной путь |
| --- | --- | --- |
| Sub OFF original URLs | Развёрнутые узлы не сохраняют исходные URL подписок. | Сохранить проект до expansion; хранить исходники локально. |
| Direct URI emitter | Не все произвольные parsed nodes можно вернуть во входные ссылки. | Исходный YAML/Studio editor или оригинальный проект; проверить unsupported report. |
| Per-Proxy listeners | Reverse не восстанавливает исходное намерение listeners точно. | Сохранить YAML, явно настроить inbound mapping; parity не обещается. |
| Raw keepalive ranges | Mihomo не выражает диапазон эквивалентно; compatibility 25 секунд меняет поведение. | Сохранить профиль/проект, выбрать compatibility option осознанно. |
| Произвольный YAML | Неподдерживаемые поля не накладываются молча на новый Build. | Сохранить исходный YAML, использовать Studio/editor, изучить Preview. |
| AWL missing fallback URL | YAML может не содержать источник для корректного fallback input. | Вернуть проект/исходный fallback; не придумывать URL. |
| Tiered custom health multi-URL | Reverse сообщает CONFLICT вместо скрытого упрощения. | Продолжить с проектом или исходным YAML. |
| Runtime routing | Выбор группы/provider/фактический маршрут статически неизвестен. | Отдельно исследовать разрешённый controller и измерить трафик. |
| CORS / реальные подписки | Offline mocks не доказывают ответы сервера/CORS. | Владелец проверяет частный непроизводственный источник и Preview/errors. |
| Keenetic/VPS/handshake | Устройства владельца и реальные маршруты не затрагивались. | Поэтапная ручная проверка ниже; production acceptance ожидается. |

## Ручная приёмка и релизные условия

1. На Windows открыть main и кандидат отдельно. Использовать локальные тестовые профили; не включать секреты в screenshots/issues. Сначала сохранить проект и исходный YAML.
2. Повторить 6 подписок +8 WG/AWG →8 +7 с нужными TUN/MIPS/WebUI/dialer/DPR. Save/reload/Load Cancel/Confirm, Build, Studio, Reverse Preview/Cancel/Confirm/Undo. Сверить настройки и явные потери.
3. На 320/390/768/1366 px проверить длинные имена и keyboard focus. В кандидате повторить Parse enabled/disabled/custom DNS, проверить UNKNOWN, затем Reverse и Parse нового Build; устаревших DNS/VRG результатов быть не должно.
4. Локальная проверка: `mihomo.exe -t -f <private-config.yaml>`. Сначала проверить `mihomo.exe -v`. Конфиги/ключи хранить локально. Parse acceptance подтверждает только разбор.
5. На отдельном тестовом VPS/Keenetic владельца сохранить backup, проверить console/recovery, вручную загрузить кандидат. Проверить controller auth, DNS, выбранные proxies, UDP/WG handshake, failover и измеренный egress; проверить поведение при отказе согласно собственной routing policy. Автоматические изменения инфраструктуры этим отчётом не разрешены.
6. Изучить точный final-head CI и отчёт, выполнить owner UI/device acceptance. При согласии дать **отдельный явный GO для #207**. До этого PR остаётся OPEN.
7. Релиз **не разрешён**: stable PR/tag/release не создавались. После owner acceptance и разрешённого merge кандидата повторно проверить получившийся main; promotion/release требует отдельного разрешения.

Оставшиеся условия: owner UI acceptance, реальные устройства/сеть для deployment claims, отдельный GO #207, отдельное разрешение stable/release. Эти условия не скрывают подтверждённый code blocker.
