## Проверенный контракт и уровень доказательности

Проверялись код, ограниченные синтетические входы, браузерные действия и реальные
скачанные файлы. Все новые browser-запросы перехватываются Playwright: CDN заменён
локальным js-yaml, контроллеры — mocks; остальные HTTP(S) запрещены тестом.
Никакой sentinel не содержит адреса эксфильтрации.

| Область | Что подтверждено | Чего это не доказывает |
|---|---|---|
| DOM/XSS | Имена proxy/group/provider, server, rules, unknown keys, topology labels отображаются текстом; sentinel не исполняется. Проверены `innerHTML` sinks: очищение контейнеров либо централизованное `escapeHtml` | Полноту всех возможных браузерных атак или безопасность установленного расширения браузера |
| YAML import | Циклы, чрезмерная глубина/aliases, большие входы, неожиданные формы и malformed YAML отклоняются ограниченной ошибкой; рабочий документ сохранён | Приём любого валидного YAML вне установленных лимитов; изоляцию парсера в worker |
| Редактор | No-op byte-identical, включая CRLF при загрузке файла; scalar edit не меняет соседний текст; последовательные rename/add/delete/rule edits проверены; Undo/Reset сохраняют оригинал | Универсальное редактирование всех YAML-конструкций и семантическую валидность любого Mihomo-конфига |
| Privacy | Известные secret values, nested headers, multiline keys, query и распознаваемые path-токены скрыты в автоматических summary/diagnostics/graph/trace/coverage/probe/ops/diff; export сохраняет настоящие значения | Автоматическое распознавание любой произвольной строки как секрета |

| UI | 320/360/390/412/480 и 1366/1920/2560 px, длинные имена, раскрытые diagnostics/graph/trace, editor, PT artifacts, runtime и footer | Все браузеры, реальные телефоны и вспомогательные технологии |

Исходный textarea и явно выбранные редактируемые поля являются рабочими данными:
они намеренно содержат оригинальный конфиг/URL. Password inputs исходным значением
не заполняются. Экспорт по явному действию сохраняет secrets; автоматически
показанные диагностические тексты должны быть redacted. Файлы не перезаписываются.

## Подтверждённые дефекты и минимальные исправления

1. **P1, import availability:** циклический alias доходил до рекурсивного scanner;
   shared alias DAG мог многократно обходиться; глубина до парсинга не ограничивалась.
   Добавлены parser-listener limits, ограниченный обход графа и shape guards.
2. **P1, availability:** LCS diff выделял `(n+1)*(m+1)` ячеек. При более чем
   1,000,000 ячеек используется линейный prefix/suffix diff. Он корректно восстанавливает
   обе стороны, но при нескольких удалённых правках может показывать больший средний блок.
3. **P1, fidelity:** CRLF файла превращался в LF, BOM терялся, invalid UTF-8 мог
   декодироваться с replacement characters. Файл теперь декодируется strict UTF-8
   с сохранением BOM, анализируется и экспортируется по исходной строке; textarea
   нормализует переводы строк по правилам браузера. Невалидные bytes отклоняются.
4. **P1, mutation correctness:** quoted/flow rules теряли квотирование при rename;
   logical rules смешивали physical и logical indices цели. Правится ровно scalar
   правила с корректным квотированием и индексом.
5. **P1, references:** delete/removeRefs пропускал flow-member references, создавая
   dangling refs. Неподдерживаемое удаление flow-ссылки теперь отклоняется;
   неоднозначные имена, затронутые anchors и структурные mutations с aliases блокируются.
6. **P1, export trust:** результат с показанным static FAIL оставался экспортируемым.
   Mutated export теперь заблокирован при FAIL и до завершения replay. Исходный
   неизменённый файл можно экспортировать, с честным PASS/FAIL оригинала.
7. **P1, privacy:** Coverage/Rule Probe обходили redaction; line masking не покрывал
   multiline/flow secrets и повторение secret value в имени/правиле. Добавлена
   document-aware redaction; новые secret edits также маскируются. Parser errors
   не печатают фрагменты исходника. JSON errors PT тоже не эхосят вход.
8. **P1, generated YAML injection:** newline/Unicode line separator в label попадал
   в YAML comment и мог добавить независимое поле. Control characters в ID/label
   отклоняются до generation. Registry/profile/evidence maps защищены от prototype keys.
9. **P1, runtime trust:** отсутствовал deadline; malformed `/version` мог не мешать
   observed result; 401 `/proxies` не назывался AUTH_ERROR. Добавлен 8 s per-node
   deadline на оба запроса/чтение body, проверка ответов, корректное auth state,
   отмена при topology input и защита от позднего ответа. Runtime secrets маскируются,
   даже если mock controller вернёт их в отображаемом поле.
10. **P2, usability:** type selector не обновлял object list, arbitrary YAML field
    key мог ломать CSS selector, длинные имена давали page overflow; некоторые
    Studio summaries имели два disclosure markers. Исправлены соответствующие места.
11. **P2, status correctness:** contract.md и manifest могли сообщать разные статусы.
    Единый status: отсутствующие данные поддерживаемого транспорта →
    PLACEHOLDERS_REQUIRED; unsupported transport/reference → EXTERNAL_CONTRACT_REQUIRED.
    При blockers config.yaml не создаётся.

Эти исправления не расширяют transport registry и не меняют generated runtime.

Независимые ограниченные reproductions на **неизменённом #192 / 043120e**:

| Fixture | Фактический результат до исправления |
|---|---|
| `x: &a {self: *a}` → secret scanner | `RangeError` |
| `rules: ["MATCH,G"]` → rename G → GG | `rules = ["MATCH", "GG"]` вместо одного правила |
| `AND,((DOMAIN,a.example.invalid),(NETWORK,UDP)),G` → target DIRECT | `rules = [null]` |
| Удалить A с removeRefs из `proxies: [A]` | удалённый A остался участником группы |
| Label `public\nexternal-controller: 0.0.0.0:9090\n#` | YAML parser видит новое поле `external-controller: 0.0.0.0:9090` |

Последний probe только генерировал/разбирал YAML; controller/server не запускался.
Квадратичная LCS allocation установлена по исходному размеру таблицы; опасный
baseline memory-exhaustion эксперимент намеренно не выполнялся.

## Явные границы импорта

- Uploaded file: максимум 2 MiB; pasted text: максимум 2,097,152 UTF-16 code units.
- Максимум 20,000 строк и 16,384 code units на строку.
- Parser nesting: 64 open events; максимум 100,000 listener events.
- Обход resolved graph: максимум 50,000 посещений и глубина 64; cycles запрещены.
- Максимум 2,000 proxies, 256 groups, 10,000 rules; shape guards для этих секций,
  members/use и provider maps. Duplicate YAML mapping keys отклоняет parser.
- Некорректные surrogate sequences отклоняются; обычный Unicode/emoji сохраняется.
- Простые anchors/aliases могут анализироваться и экспортироваться без изменений.
  Структурные mutations с aliases отклоняются; независимый scalar edit разрешён.
  Anchored scalar/object нельзя менять через scalar editor.

Парсинг остаётся синхронным в UI thread. Лимиты — практическая ограниченная защита,
а не формальная гарантия CPU/memory для любых устройств. Нужен повторный UX-check
на целевом телефоне/роутере владельца, особенно около верхних границ.

Один наблюдённый прогон Windows / Node v24.19.0 / headless Edge, 2026-10-08.
Миллисекунды; fixtures содержат только synthetic passwords и RFC5737 endpoints.
Это не универсальный benchmark и не обещание latency. Прогоны зависят от нагрузки.

| Parsing + bounds | 6.4 | 37.1 |

| Graph text + DOM layout | 1.4 | 1.8 |
| Import + analysis + editor UI | 14.5 | 48.7 |
| Scalar replay edit | 51.3 | 328.0 |

10 s — защита от зависания теста, а не acceptable UI latency.

## Offline, network и внешние компоненты

| Действие | Сеть / данные |
|---|---|
| Открытие страницы | js-yaml CDN (pinned + SRI); остальные scripts локальные. `file://` поддерживается |
| Config Studio parse/analyze/edit/export | Offline; providers не скачиваются; original и operations только в памяти |
| PT analyze / What-if / generation / downloads | Offline; What-if — owner-declared static model |
| Runtime Evidence | Только explicit button: browser → controller `/version`, `/proxies`; Bearer secret в header; endpoint/profile не сохраняются |
| Subscription preview/expansion в Builder | User-triggered Build/preview может обратиться к subscription; при direct/CORS failure — owner-controlled subscription proxy. Это отдельный сетевой путь, не Config Studio |
| Generated config в Mihomo | После deployment сам Mihomo может делать provider/health-check/DNS/proxy запросы; приложение их не доказывает |

Per-node first-class templates: `ss`, `socks`, `http`. Остальные серверные стеки
требуют внешнего компонента и отдельного контракта. У demo финальный WireGuard
overlay остаётся EXTERNAL_CONTRACT_REQUIRED. READY означает полноту шаблона
генератора, а не готовность инфраструктуры или безопасность открытого listener.
Socks/HTTP templates не добавляют authentication: owner должен обеспечить изоляцию
и допустимую область доступа до запуска; публичный unauthenticated listener недопустим.
Этот аудит не менял firewall и не запускал серверы из сгенерированного конфига.

## Owner field-test checklist — примерно 10–15 минут

Использовать отдельную копию рабочего конфига и доступную owner test environment.
Не публиковать YAML, secrets, controller URLs или полные скриншоты inputs.

1. **0–2 мин:** убедиться в версии actual Mihomo binary (1.19.31/1.19.32), сохранить
   исходный файл и проверить его `mihomo -t -f config.yaml` в owner environment.
2. **2–4 мин:** Config Studio → импорт копии → no-op download → byte compare с
   оригиналом. Проверить summary/diagnostics и отсутствие secrets в preview.
3. **4–6 мин:** изменить один server/port, проверить diff и downloaded YAML,
   выполнить `mihomo -t`; Undo/Reset → download должен совпасть с оригиналом.
4. **6–8 мин:** provider URL edit на synthetic copy; убедиться, что preview скрывает
   токен, скачанный конфиг содержит правильное значение. Used-proxy deletion должен
   показать impact и не оставить dangling refs; unsupported flow case отклоняется.
5. **8–10 мин:** PT demo → analyze → What-if отказ middle hop → chain unavailable;
   generation → проверить статусы и отсутствие config.yaml у external-contract узлов.
   Для собственной spec проверить inbound/outbound, порты, credentials, роли,
   изоляцию listener и единственный предусмотренный final Internet DIRECT.
6. **10–12 мин:** если owner имеет безопасно доступные test controllers, выполнить
   explicit Runtime Evidence; проверить bindings и сравнить controller selection.
   Поменять профиль/топологию → STALE; unreachable не означает VPS down.
   При отсутствии controllers оставить runtime NOT CHECKED, не подменять его PASS.
7. **12–15 мин:** проверить рабочий браузер/телефон: 320–480 px, keyboard focus,
   раскрытие diagnostics/trace/diff/export; закрыть вкладку, убедиться, что secrets
   не восстановились из storage. Зафиксировать версию core и результат field-test
   без secrets. Наличие storage HWID registry само по себе не является утечкой.

Реальный packet path, DNS/IP leaks и межузловой failover требуют отдельного owner
deployment/packet-level acceptance. Этот короткий checklist их не заменяет.

## Release recommendation

**READY FOR OWNER FIELD-TEST при зелёном exact-head CI.** До owner field-test
продукт не является production-proven. Physical Topology, per-node templates и
Runtime Evidence остаются ограниченными v1.11 workflows с явными статусами;
packet-path proof отсутствует. Promotion `main → stable` и release требуют
отдельного owner решения по установленному release invariant.
