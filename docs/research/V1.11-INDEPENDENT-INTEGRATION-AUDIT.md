## 1. Findings

### QA-01 — P2: DPR + Tiered Failover вместе → валидатор отвергает сборку
- **Affected:** Domain Policy Routing × Tiered Failover.
- **Repro:** включить обе опции (карточка DPR + карточка Tiered, профиль router), Build → INVALID: «последнее правило должно быть MATCH,GLOBAL» — Tiered-патч переписывает финальный `MATCH,GLOBAL` в `MATCH,🪜 TIERED-AUTO`, а DPR-контракт валидатора его требует (`index.html`, проверка `ruleProviderNames.size`).
- **Expected:** либо сборка проходит (валидатор учитывает Tiered-корень), либо явный запрет комбинации ДО сборки.
- **Actual:** сборка блокируется ПОСЛЕ построения, с ошибкой про GLOBAL, которая не называет реальную причину (конфликт опций).
- **Root cause:** контракты двух фич не согласованы (Tiered добавлен позже DPR).
- **Evidence:** воспроизводится в фазе A `qa-reverse-integration.cjs` @ `1091492`; ошибка явная (не молчаливая порча) — потому P2, не P1.
- **Regression test:** фаза A теста.
- **Suggested fix:** валидатору принимать `MATCH,🪜 TIERED-AUTO` при активном Tiered, либо up-front кламп «DPR и Tiered несовместимы» с понятным текстом. Продукт-фикс — отдельным PR (не в этом аудите).

### QA-02 — P3: page-валидатор пропускает невалидный base64 в `private-key`
- **Repro:** WG-профиль с некорректным base64-ключом → page-валидация VALID, реальный `mihomo -t` отвергает («decode private key: illegal base64 data»).
- **Mitigation:** UI честно пишет «Это не эквивалент проверки mihomo -t»; после QA-фикстуры (валидные ключи) `mihomo -t` — successful.
- **Suggested fix (P3):** добавить в валидатор проверку формата base64/длины 44 для ключей WG. Не блокирует релиз.

### Позитивный результат (главный)
Полный интеграционный сценарий владельца — **6 URL-подписок + 8 WG/AWG (4 WG + 4 AWG) + DPR + Exclude Filter + TUN/MIPS + WebUI, профиль router** — прошёл end-to-end:
Save project → чистая вкладка → Load (поле-в-поле) → Build (byte-parity) → **−1 AWG +2 подписки → Build VALID** → 7 WG/AWG, 8 подписок, ключи остальных 7 профилей в YAML, DNS (remote-dns-resolve), DPR-правила, MIPS/WebUI/exclude-filter не тронуты, dangling нет → **`mihomo -t`: «test is successful»** (реальный mihomo 1.19.31). Фаза C: YAML Reverse того же конфига → Restore → Build — байт-эквивалент.
