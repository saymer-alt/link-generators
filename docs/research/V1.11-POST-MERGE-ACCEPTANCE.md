## Известные ограничения YAML Reverse

| Ограничение | Действие владельца |
| --- | --- |
| Expanded Sub OFF YAML не содержит URL подписки | Сохранить исходный Project/URLs до expansion. Project roundtrip и Reverse из YAML имеют разные границы. |
| Произвольный direct node не всегда восстанавливается в URI | Сохранить исходный YAML/Project; изучить MISSING/UNSUPPORTED report. |
| Per-Proxy listeners не восстанавливают исходное намерение полностью | Явно сверить inbound mapping; не ожидать полной parity. |
| Raw keepalive range | Compatibility 25 — осознанное изменение поведения, не эквивалент диапазона. |
| Arbitrary YAML / unsupported fields | Не накладываются молча на свежий Build; хранить исходник и просматривать Preview. |
| AWL fallback URL отсутствует в YAML | Вернуть оригинальный Project/fallback input; источник не выдумывается. |
| Tiered custom multi-URL health-check | CONFLICT вместо скрытого упрощения; использовать исходный проект/YAML. |
| Runtime member/provider/route | UNKNOWN без отдельного наблюдения controller/трафика. |

## Реальная сеть и уровни доказательств

Parse acceptance, process start, loopback traffic и WAN handshake — разные стадии. Обязательная loopback lab в CI проверяет DIRECT/proxy, DNS mock ON/OFF, A→B failover и B→A recovery на обеих версиях, с TUN/sniffer OFF. Это не proof WG/UDP/WAN или реального отсутствия DNS leaks. Реальные subscriptions/CORS, VPS/Keenetic владельца, DNS leakage/egress и remote handshake — NOT RUN. Windows1.19.32 локально NOT RUN из-за ранее установленной upstream asset anomaly; Linux1.19.32 проверен CI.

## Main preview и Windows PowerShell

Post-merge artifact проверен через GitHub API: `link-generators-main-preview`, ID11624767534, не expired, срок хранения до 23.10.2026. ZIP скачан локально; index.html содержит DNS panel, runtime bundle присутствует. Production Pages не перенастраивались. После PR материалов используйте самый новый зелёный preview run из итоговой передачи.

```powershell
# Нужен установленный gh с доступом к Actions; выполнять в отдельном локальном каталоге.
gh run download 37947899936 --repo saymer-alt/link-generators `
  --name link-generators-main-preview --dir .\v111-preview-download
Expand-Archive .\v111-preview-download\link-generators-main-preview.zip `
  -DestinationPath .\v111-owner-preview
Start-Process (Resolve-Path .\v111-owner-preview\index.html).Path
```

Для локального checkout: `Start-Process (Resolve-Path .\index.html).Path`. js-yaml нужен при Parse; обычный preview использует CDN. Offline acceptance harness подменяет CDN локальным файлом. Не прикладывать приватные YAML/Project/keys к issues/screenshots.

Безопасная **parse-only** проверка настоящим заранее установленным Mihomo:

```powershell
$mihomoPath = (Resolve-Path .\tools\mihomo.exe).Path
$configPath = (Resolve-Path .\private\config.yaml).Path
$parseDir = Join-Path $env:TEMP ('mihomo-parse-' + [guid]::NewGuid())
New-Item -ItemType Directory -Path $parseDir | Out-Null
& $mihomoPath -v
& $mihomoPath -t -d $parseDir -f $configPath
if ($LASTEXITCODE -ne 0) { throw 'Mihomo parse rejected; keep diagnostics private' }
```

Использовать version1.19.31 или1.19.32 и доверенный binary. `-t` не запускает traffic process/TUN и не меняет маршрутизацию/DNS ОС; geodata/provider dependencies могут требовать локальных ресурсов или сетевого получения, поэтому для полностью offline проверки используйте synthetic config без GEO/provider downloads либо заранее подготовленные ресурсы. Не запускать команду без `-t` как часть этой инструкции. Parse PASS не доказывает handshake/маршрут. Временный каталог можно удалить вручную после проверки; приватные diagnostics не публиковать.
