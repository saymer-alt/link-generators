# V1.11 Owner UI Test Plan (NIGHT-QA-01)

Дата: 2026-10-09. Аудит-базис: main `1091492`. Назначение: минимальный, воспроизводимый план ручного UI-теста владельцем перед OWNER GO. Никаких real credentials; на реальных конфигах — только свои.

## 1. Подготовка

1. Открыть `index.html` локально (file://) в актуальном Edge/Chrome.
2. Подготовить: 2–3 своих URL-подписки, 2–3 WG/AWG-файла (в т.ч. один AWG 3.x).

## 2. Builder (15 мин)

- [ ] Вставить подписки (Sub Mode ON) + загрузить WG/AWG → Build → VALID, YAML смотрится.
- [ ] Toggle TUN/MIPS/Allow-LAN/WebUI — пересборка меняет только соответствующее.
- [ ] Exclude Filter (вписать выражение) → Build → `exclude-filter` в провайдерах.
- [ ] DPR-карточка → Build → `policy-*` + RULE-SET. **Отдельно проверить вместе с Tiered** (известный QA-01: вместе INVALID — подтвердить, что ошибка понятна).
- [ ] Tiered-карточка (без DPR) → Build → `🪜 TIERED-AUTO`.
- [ ] Удалить один WG-профиль → Build → узел исчез, остальные на месте.

## 3. Проект и Reverse Build (15 мин)

- [ ] «💾 Сохранить проект» → предупреждение о секретах → файл скачан.
- [ ] Обновить страницу (F5) → «📂 Загрузить проект» → Builder восстановлен → Build → YAML эквивалентен (x-hwid в провайдерах — случайный, это норма).
- [ ] Изменить состав (−1 WG, +1 подписка) → Build → изменения точечные.
- [ ] Скопировать итоговый YAML → Config Studio → «Разобрать» → «🔁 Восстановить в Builder» → отчёт обратимости → Build → сравнить с исходным YAML.

## 4. Config Studio / VRG / PT (10 мин)

- [ ] Studio: сводка, диагностики, «Маршрутизация» по домену, редактор (одно поле) → diff → экспорт gated на валидацию.
- [ ] VRG в Builder: граф после Build, клик по узлу (фокус), Enter/Space, сброс; в Studio после «Разобрать».
- [ ] PT-панель: demo-топология → what-if отказ узла → CHAIN UNAVAILABLE.

## 5. Ручная проверка секретов (5 мин)

- [ ] Приватный ключ WG виден в скачанном YAML и проекте (функционален), но НЕ в статусах/тостах/отчётах на экране.

## 6. Критерии GO

Все пункты без неожиданностей; известные оговорки: QA-01 (DPR+Tiered), QA-02 (base64 валидация — P3), x-hwid недетерминизм. Любое расхождение — в issue со скриншотом и шагами.
