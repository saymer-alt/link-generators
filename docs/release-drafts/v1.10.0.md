v1.10.0 — тема Routing + Subscription + Runtime + AWG Intelligence: строгие эшелоны
выходов, честный subscription-preview с authoritative источником из работающего Mihomo,
стабильная identity устройства для панелей подписки и определение поколений WG/AWG.

## Главное

- **Tiered Failover (#148)**: «🪜 Приоритетные эшелоны выходов» (по умолчанию ВЫКЛЮЧЕНО) —
  строгий приоритет: трафик идёт через первый живой эшелон; runtime-семантика доказана на
  реальном Mihomo 1.19.31/1.19.32.
- **Mihomo Runtime Node Import (#159)**: спросить сам работающий Mihomo, какие узлы
  провайдеров он загрузил (GET /providers/proxies; direct/paste/upload; read-only) и
  отметить их в Exclude Filter — authoritative источник при расхождении с browser-preview.
- **Device identity (#156/#163)**: один логический роутер = один стабильный HWID для
  preview и всех провайдеров; пересборки не ротируют identity; управление — явное
  (переименование / «🎲 Сменить ID» / удаление лишних).
- **WG/AWG generation badges (#157)**: карточки профилей показывают поколение (WG /
  AWG 1.x / 1.5–2.x / 3.x / 3.1 / AWG ?) с честной уверенностью и доказательной
  матрицей; без ложных точных версий.

## Добавлено

- Honest preview (#158): «⚠ Preview неполный» при отброшенных схемах; явное сообщение
  при Clash/Mihomo YAML; reconciliation Preview ∩ Runtime.
- Config Dependency Graph + Domain Coverage были в v1.9 — в v1.10 они видят эшелоны.
- Resizable список узлов (#166); compact UX карточек эшелонов (#165).

## Исправлено

- Subscription preview (#152): залипание «Загрузка…», UNKNOWN ≠ 0, живые сводки
  (union без double-count), ограниченный бюджет preview-операции, диагностика
  fallback-этапа («Direct: …; Fallback: …»), Device Model выше Exclude Filter.
- Tiered race (#165): незафиксированный выбор участника больше не теряется при
  перерисовке.

## Безопасность и приватность

- Controller secret/runtime JSON — только память вкладки; запросы к контроллеру никогда
  не идут через проектный воркер; HWID нигде не отображается; localStorage — только
  реестр идентичностей; owner LAN-пример заменён на synthetic.

## Совместимость и границы

- Mihomo minimum 1.19.31 (MIPS stack, DDP), recommended/current 1.19.32; v3-семантика
  AWG требует ≥ 1.19.30.
- Tiered Failover: HTTP-пробы only (UDP не заявлен); имена эшелонов детерминированы.
- Runtime Import: браузер должен суметь достучаться до контроллера (listen/CORS/PNA);
  fallback — paste/upload JSON.
- Панель подписки может дедуплицировать устройства по-своему (HWID vs UA) — UNKNOWN;
  генератор больше не создаёт расщепления идентичностей со своей стороны.
- Preview подписки честно маркируется как неполный при неизвестных схемах; полный
  список — только из работающего Mihomo.
