## Тестовый контракт v1.12

Каждый подтверждённый дефект: **автоматический тест RED на исходной версии → GREEN после исправления**. Для UX нужны поведенческие Playwright browser assertions (не поиск строк), Chromium/Firefox/WebKit, mouse+keyboard, narrow viewport, миграция проектов, проверка Build/YAML parity и negative/DOM-tamper. Новые `tests/*.cjs` явно подключать к `.github/workflows/generator-ci.yml`.

При изменении движка — source repo `web4core` и provenance; `web4core.runtime.js` вручную не менять. Все релизные кандидаты должны иметь зелёные Node/browser/Mihomo 1.19.31/1.19.32 CI там, где применимо, и честные границы field acceptance: `mihomo -t` не доказывает живой handshake/UDP/DNS или отсутствие утечек.
