## 2. Exact future sequence (после owner GO)

1. **Owner GO received** — зафиксировать в issue/комментарии дату и ссылку на заполненные
   RESULTS (локальный файл присылается sanitized).
2. **Verify main SHA unchanged**: `git fetch && git rev-parse origin/main` ==
   `13a21f65d7b87038ba25e82e3ccdc9057c2e4c3e`. Если сдвинулся (docs/fix) — field-test
   затрагивал другой SHA → оценить дельту; при product-дельте вернуться к владельцу.
3. **Promote**: ветка от `origin/stable` → `git merge origin/main` (ожидаемо clean;
   конфликтов быть не должно — stable-only коммиты касаются промо/CI-смоука) → коммит
   «release: promote v1.10.0 (GENERATOR_META 1.10.0/stable)» с точечной правкой
   `GENERATOR_META` → PR в `stable` → merge ТОЛЬКО после зелёного CI на PR.
4. **Verify stable SHA**: `git rev-parse origin/stable` == merge commit промоушена;
   `git show origin/stable:index.html` содержит `version: '1.10.0', channel: 'stable'`.
5. **Release metadata**: имя `v1.10.0 — <короткое название>`; body из
   `docs/release-drafts/v1.10.0.md` с заполненными секциями «Проверено» (факты field-test)
   и provenance (п.7).
6. **CI on stable**: дождаться зелёных Generator CI + Update web4core runtime на новом
   stable (write-back на stable запрещён — только read-only проверка).
7. **Tag**: аннотированный `v1.10.0` на промо-HEAD stable; проверить
   `git rev-parse v1.10.0^{commit}` == stable HEAD. Push тега.
8. **Verify peeled**: повторить проверку после push (`git ls-remote --tags origin`, `^{}`).
9. **Publish GitHub Release** из approved draft (Profile A: без H1-дубля, секции
   «Главное/…/Совместимость и границы», provenance-футер с промо-SHA). Latest=true,
   draft=false, prerelease=false.
10. **Verify Latest**: `gh release list` → v1.10.0 Latest; тег → промо-SHA.
11. **Production verification**: открыть Pages (Ctrl+Shift+R), бейдж = `v1.10.0 · STABLE`;
    смоук: обычная сборка, subscription preview, runtime import (доступность),WG/AWG бейджи;
    Pages build record указывает промо-SHA.
12. **Bootstrap v1.11.0-dev** — ТОЛЬКО после успешного релиза и отдельного решения:
    GENERATOR_META на main → `1.11.0-dev`, свежий scope-issue. До этого main остаётся
    `1.10.0-dev`.
