# Release notes draft — v1.9.0 (DRAFT ONLY)

> Черновик для будущего GitHub Release (Profile A RELEASE-STANDARD.md).
> Не публикуется: тег, Release и promotion создаются только владельцем после
> ручного field-test; SHA в provenance-строке проставляется на promotion.
> Пункт «Проверено» заполнить фактическими результатами на момент релиза.

v1.9.0 открывает тему Configuration Intelligence: генератор теперь не только собирает
конфиг, но и объясняет маршрут, покрытие доменов и то, что он изменил в пользовательском
вводе, — плюс полная поддержка импорта WARPSCOUT/MASQUE и явные AWG-настройки стабильности.

## Главное

- **WARPSCOUT-aware MASQUE import**: генератор распознаёт YAML с `type: masque`, переносит
  точные endpoint/SNI каждого транспорта (H3/QUIC и H2/TCP) и объясняет решение;
  несовместимые identity и неизвестные транспорты отвергаются явно.
- **AWG stability (#137)**: явные переключатели «🛡 NAT keepalive 25 с» (вкл. по умолчанию)
  и «🧪 Тест обрывов: отключить RandomTrailers» — без ручного редактирования .conf.
- **Routing Intelligence**: семантический путь правил в Inspector, честная маркировка
  устаревшей диагностики и новый Domain Coverage Checker.

## Добавлено

- Импорт WARPSCOUT/MASQUE YAML: сканирование всех прокси, точные endpoint'ы на транспорт,
  селектор при неоднозначности, fail-closed на несовместимую identity и неизвестные сети.
- Секция «⚙️ Advanced MASQUE»: точный endpoint/SNI, свои списки портов, приоритет
  «точный endpoint → порты → встроенная стратегия».
- «🛡 Поддерживать AWG-соединение через NAT (keepalive 25 с)» — по умолчанию включено;
  существующее целое значение не меняется; диапазон сводится к 25 с явной диагностикой.
- «🧪 Тест обрывов: отключить RandomTrailers» — по умолчанию выключено; диагностический
  эксперимент с предупреждением.
- Domain Coverage Checker: для списка доменов — победившее правило, провайдер,
  статический путь до цели (с dialer-цепочками), честные UNKNOWN/UNCOVERED/INVALID.
- Upstream compatibility registry (Any-Tech-ARCHITECT → Mihomo) со слежением за
  изменениями исходников и уровнями доказанности.
- Research-документация: MTU-модель WireGuard/AWG, классы runtime-отвалов, полевые
  контракты WARPSCOUT.

## Изменено

- Таргет политики «Отдельная группа выбора» → «🎛 Своя SELECT-группа (переключается в Mihomo)».
- Routing order и «Проверить домен» показывают тип группы и фактический состав участников
  из итогового конфига вместо двусмысленного «правило → группа с тем же именем».
- Диагностика помечает устаревший snapshot после изменения настроек (без скрытой пересборки).
- Шаблон политики «🚀 Proxy (свои домены через прокси)» (симметрия к «⬇️ Direct»).
- Бейдж версии: development-сборки показывают `vX.Y.Z-dev · MAIN`.

## Исправлено

- Несовместимая пара H3+H2 из разных WARP-аккаунтов больше не может быть импортирована
  как гибрид — явный fail-closed отказ.
- Ключ, найденный в неподдерживаемом кандидате, больше не «валидирует» поддерживаемый
  профиль без собственного ключа.
- Стейл-состояние от предыдущего импорта (поля, бейдж) не переживает новый MASQUE-парс.

## Безопасность

- Ключи и точные endpoint живут только в памяти страницы: ни localStorage/sessionStorage,
  ни URL, ни логи; значения секретов не печатаются в диагностиках (только имена профилей
  и полей).
- Браузер не обращается к GitHub/upstream за compatibility-данными; реестр — локальный.

## Проверено

- Generator CI: детерминированные node/browser-регрессии, mihomo `-t` матрица 1.19.31 и
  1.19.32, parity, runtime provenance, Architect watcher (заполнить ссылками на runs).
- Ручной field-test: docs/RELEASE-FIELD-TEST-v1.9.md (заполнить владельцем).

## Совместимость и границы

- Минимальный Mihomo: 1.19.31; рекомендуемый: 1.19.32.
- MASQUE-контракт IPv6 endpoint не доказан — такие endpoint'ы отвергаются явно.
- Fixed keepalive 25 под диапазон — user-visible compatibility policy, не эквивалент
  исходной random-range семантики; отключается переключателем.
- `mihomo -t PASS` означает принятие синтаксиса/схемы, не гарантию runtime-семантики.
- Auto-MTU остаётся выключенным (диагностика MTU — без изменения YAML); watchdog/auto-restart
  не входят в генератор.
- Node/colo/SNI из сканов — наблюдения, а не постоянные свойства endpoint'ов.
