## План ручной проверки владельцем (без риска для работающего роутера)

1. Открыть `index.html` из `main` (локально file:// или черновой Pages preview), убедиться: в шапке видны «🔑 Идентичность подписки (Mihomo Builder)» и маска HWID.
2. «👁 Показать HWID» → полный ID; повторный клик скрывает; «📋 Копировать HWID» → буфер.
3. «➕ Другое устройство» → переключение в шапке; собрать тестовый конфиг (Sub Mode ON, синтетическая подписка) → `x-hwid` в YAML соответствует выбранному устройству; после смены устройства — баннер STALE.
4. Подготовить переносимый v2: «🔐 Подготовить переносимый проект v2» (подтвердить предупреждение о секретах) → назначить второй подписке отдельный HWID → «💾 Сохранить проект».
5. Загрузить v2-файл на другой машине/в чистом профиле → реестр браузера не изменился → Build → провайдеры несут сохранённые HWID (A=H1, B=C=H2).
6. «Получить список» на недоступной подписке → «⏹ Пропустить» → статус «количество узлов неизвестно», сеть обрывается; сборка provider YAML работает и без списка.
7. `# provider-name: Имя` перед URL → имя в MetaCubeXD.
8. На отдельной копии конфига в Mihomo (не на рабочей): `mihomo -t` + запуск, ручной GLOBAL → Tiered → fallback → ручной GLOBAL.
