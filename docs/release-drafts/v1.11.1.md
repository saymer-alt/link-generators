Патч улучшает контекстные подсказки, объясняет работу URL-подписок и упрощает импорт имён узлов из работающего Mihomo. Парсинг и генерируемые конфигурации сохраняют прежнее поведение.

## Главное

- Подсказки, включая динамические WG, остаются внутри viewport; учтён классический scrollbar и поведение Firefox.
- Рядом с основным вводом объяснены proxy-ссылки, подписки и отдельные WG/AWG-файлы; доступен переход к настройке подписок без переключения значения.
- Runtime importer предлагает готовые адреса и свой endpoint; API secret отправляется на нового получателя только после подтверждения.

## Добавлено

- Presets `192.168.1.1:9090`, `192.168.0.1:9090`, `127.0.0.1:9090` и «Свой адрес…» в существующем импортере `GET /providers/proxies`.

## Исправлено

- Обрезание tooltip у Allow LAN/TUN; ограничены реальные ширина и высота, длинный текст прокручивается, позиция обновляется при scroll/resize и после Firefox hover styles (PR #267).
- Уточнено смешивание обычных proxy-ссылок и URL-подписок **в обоих режимах**: ON сохраняет динамические providers, OFF читает подписку по явному Build и встраивает её текущие узлы (PR #269).
- При смене endpoint отменённый runtime-запрос больше не оставляет статус «Загрузка…» (PR #270).
- Вместо пустого advanced select видно «Выберите system / mixed», включая восстановление старого проекта с gVisor. Выбор остаётся явным, настройки SOCKS-only/TUN/Per-Proxy не разблокируются (PR #272).

## Безопасность

- Runtime importer по-прежнему читает только `GET /providers/proxies` по кнопке; выбор/ввод адреса не запускает запросы или сканирование.
- Новый получатель API secret требует подтверждения; адрес и secret остаются в памяти вкладки, не записываются в проект/localStorage и не передаются через fallback worker.
- Выбираемый адрес runtime controller **не меняет** `external-controller`, bind/listen, WAN или настройки VPS в генерируемом YAML.

## Проверено

- Chromium, Firefox, WebKit: geometry/scrollbar/scroll/resize, mouse/keyboard, динамические подсказки, Sub Mode, runtime mocks/secret consent и Project roundtrip.
- Полный Generator CI: node/browser, Owner Experience Gate, Config Studio/Save/Load/Reset/Reverse, security/privacy/stress, AWL/Tiered/DPR, runtime provenance, реальные Mihomo **1.19.31 и 1.19.32**.
- YAML byte parity со stable v1.11.0: **10/10** неизменённых сценариев. Exact candidate/production SHA, CI и Pages фиксируются в [отчёте выпуска #273](https://github.com/saymer-alt/link-generators/issues/273).

## Совместимость и границы

- **POST-RELEASE FIELD / NOT RUN:** native Firefox zoom **150/200/250/300%** на компьютере Владимира ещё не проверялся. Владелец перенёс эту ручную приёмку на публичную версию после выпуска; автоматические headless/viewport тесты её не заменяют.
- Полный RU/EN-переключатель и расширение TUN/MIPS в SOCKS-only оставлены для v1.12 и не входят в патч.
- Статические графы и `mihomo -t` не доказывают настоящий маршрут, отсутствие DNS leaks или WG/AWG handshake. Реальные контроллеры, VPS и роутеры не изменялись.

Тег `v1.11.1` идентифицирует принятый production-коммит `stable`; exact SHA и результаты проверок опубликованы в GitHub Release и Issue #273.
