# Подготовка v1.11.3 — фильтр серверов подписки и понятный импорт исключений

**Статус:** release candidate, не опубликовано. Дата подготовки: 2026-10-22. База: production `stable` v1.11.2. Источник изменений: [PR #311](https://github.com/saymer-alt/link-generators/pull/311). Без переноса незавершённой ветки 1.12.

## Имя GitHub Release

`v1.11.3 — понятное исключение серверов подписки`

## Текст GitHub Release (начинается с абзаца; заголовок НЕ дублировать)

В этом небольшом исправлении генератор яснее объясняет, какие серверы из подписки будут исключены. Патч подготовлен по результатам реального использования: пользователь отметил все серверы, кроме Германии, полагая, что галочки их разрешают, и получил противоположный результат.

## Главное

- В списке имён постоянно написано: **галочка исключает сервер**, не разрешает его. Кнопки названы «Исключить все показанные» и «Снять все галочки»; действие поиска сохранено.
- Показаны разные источники исключений: галочки, ручной регулярный фильтр и их пересечение. Снятие галочек не очищает ручной фильтр.
- Появляется предупреждение при исключении всех или не менее 90% известных имён.
- Сводка preview различает количество полученных узлов и **количество уникальных имён** после фильтрации; больше нет вычитания уникальных имён из числа физических узлов.
- В справке уточнено: отмеченное имя экранируется, но по текущей семантике regex ищется как **подстрока**. Поэтому совпадение может захватить и более длинное название. Проверка привязанных exact-match исключений выделена в [#312](https://github.com/saymer-alt/link-generators/issues/312).

## Проверено

- Browser regression: сценарий исключений, поиск, исключение всех, порог 90%, ручной фильтр и дублирующиеся имена.
- Generator CI: статические, Chromium, Firefox/WebKit, проверка с Mihomo 1.19.31/1.19.32; результаты сверяются **для окончательного release commit**, а не ранее проверенного PR-коммита.
- Проверка YAML parity: незатронутые конфигурации должны сохранить прежнюю семантику; `web4core.runtime.js`, HWID, proxy routing, DNS и TUN не менялись.

## Совместимость и границы

- Существующие конфигурации на роутерах не изменяются автоматически, требуется явная пересборка и импорт.
- Фильтрация имён **не изменена**: это прежде всего исправление интерфейса, диагностических счётчиков и предупреждений.
- Preview может быть частичным из-за формата подписки, CORS и различий с runtime Mihomo. Счётчики основаны на известных именах и не гарантируют фактическую доступность серверов.
- Зелёная проверка YAML не гарантирует работу камер, UDP/P2P и конкретных внешних маршрутов.
- Функции и архитектурные работы 1.12, отдельные HWID per-provider и прямое управление LAN-конфигом в релиз не включены.
