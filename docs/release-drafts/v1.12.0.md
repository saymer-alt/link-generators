# v1.12.0 — переносимые HWID и понятная работа с подписками

**Дата кандидата:** 31 октября 2026. **Исходный проверенный `main`:** `38ea810db2ba51eeb758f0bd30474b1f119f06d2`. **Статус документа:** текст для будущего релиза, публикация только после `stable` CI + Pages smoke и проверки соответствия финальному SHA.

## Текст GitHub Release

В v1.12.0 улучшены работа с HTTP-подписками Mihomo, выбор логических устройств и переносимость проектов между браузерами. Генератор остался статическим браузерным инструментом; существующие конфигурации роутеров и VPS автоматически не меняются.

### Новое
- **Верхняя панель устройства/HWID.** Активное логическое устройство доступно до Preview/Build; HWID маскируется, раскрывается/копируется только явно. Смена устройства делает старую сборку STALE. Панель правильно различает локальную модель v1 и переносимые идентичности v2.
- **Переносимые проекты `.lgproject.json` v2.** Опционально разные стабильные HWID для разных подписок, один HWID для нескольких провайдеров и явные подписки без HWID. Сохранение/импорт сохраняют привязки без перезаписи реестра текущего браузера. **Файл проекта может содержать настоящие HWID и секреты — храните его как конфиденциальный.**
- **Имена провайдеров.** Ручная пометка `# provider-name: Имя` перед URL; имена отображаются в `proxy-providers` и MetaCubeXD, не меняя сами subscription URL.
- **Получение списка серверов и понятный отказ.** Кнопка «⏹ Пропустить» реально отменяет сетевую операцию; недоступное Preview сообщает «количество узлов неизвестно», а не выдуманный ноль. Доступен понятный ручной путь через JSON работающего Mihomo без DevTools. Генерация provider YAML возможна без Preview.

### Совместимость и границы
- Положительный полевой результат 31.10.2026: владелец получил список серверов из настоящей подписки **дома** на v1.12-dev. Ранее на работе запрос не удавался; **v1.12 из рабочей сети ещё не перепроверена**, причина старого `ERR_CONNECTION_CLOSED` не доказана.
- **Строгий Preview portable v2 может отказывать:** обновлённый Cloudflare Worker `strict-same-origin-v1` подготовлен в исходниках, но не развёрнут. Пока он не обновлён, Builder может собирать v2 YAML, однако строгую удалённую проверку с HWID не следует объявлять работающей. Это намеренное fail-closed поведение; не обходите защиту браузера.
- Preview подписок зависит от сетевой доступности, CORS/Worker и возможностей провайдера. Успех дома не гарантирует успеха на другой сети.
- **Не включено:** draft #286 с семантическим запретом прямого пользовательского egress с публичного IP VPS. Не полагайтесь на v1.12 как на новую защиту от такого выхода. Служебная загрузка подписок не равна утечке клиентского трафика.
- **Не включено:** полный RU/EN, provider health/path/interval, group-level exclude-filter, full Config Studio 3.0, WDTT. Эти функции заморожены до следующего цикла.
- Проверки CI (Node, Chromium/Firefox/WebKit, Mihomo 1.19.31/1.19.32) не заменяют проверки реальных OS firewall/PBR, DNS/IPv6, UDP-handshake или внешних клиентов. Не заменяйте рабочий конфиг VPS без отдельной безопасной приёмки.
- `stable` и публичный Pages должны показывать **`v1.12.0 · STABLE`**. Production-тег `v1.12.0` создаётся только на точном проверенном финальном SHA `stable`, никогда на dev/main/head PR.
