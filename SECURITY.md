# Политика безопасности / Security Policy

Этот файл описывает **ответственное сообщение об уязвимостях**, но **не включает** настройку GitHub Private Vulnerability Reporting сам по себе. Его состояние необходимо проверить отдельно в настройках репозитория.

## Поддерживаемая область

Актуальный веб-генератор, опубликованный через GitHub Pages из `stable`, и разрабатываемая ветка `main`. Архивные версии не сопровождаются автоматически.

Обработка приватных ключей, конфигураций и подписок в браузере; прямые запросы к подпискам и fallback Cloudflare Worker; авторизация Mihomo Controller; генерация и проверка YAML; загрузка сторонних библиотек. Перед отчётом изучите [`docs/DATAFLOW.md`](docs/DATAFLOW.md). Фактическое хранение/логирование на внешнем Worker не подтверждено публичным кодом.

## Как сообщить об уязвимости

1. Откройте [Security Advisories](https://github.com/saymer-alt/link-generators/security/advisories).
2. Если GitHub показывает кнопку **Report a vulnerability**, используйте её для приватного сообщения. Это предпочтительный канал: отчёт не появляется в публичных Issues.
3. **Если кнопки нет:** приватная форма для этого репозитория недоступна или её статус не подтверждён. **Не публикуйте** технические подробности уязвимости публично. При необходимости создайте Issue с заголовком «Запрос приватного контакта по безопасности», **без** PoC, токенов, эксплойтов, адресов целей и иных чувствительных деталей — только просьбу согласовать приватный канал. Это не заменяет приватное сообщение.

Не существует указанного в этом репозитории подтверждённого публичного email для уязвимостей; не отправляйте конфиденциальные сведения на случайные контакты из профилей.

## Что включить в приватный отчёт

- Затронутую версию, платформу и предполагаемое воздействие.
- Минимальные воспроизводимые шаги с **синтетическими**, а не реальными секретами.
- Оценку последствий и безопасную рекомендацию по исправлению, если она известна.
- Сообщение о том, публиковалась ли проблема ранее.

**Не загружайте** реальные закрытые ключи, URL подписок с токенами, пароли, приватные журналы, IP-инвентари и подробности чужой инфраструктуры.

## Координированное раскрытие

До согласования исправления просим не публиковать детали, позволяющие эксплуатацию. Срок ответа и исправления не гарантирован: проект сопровождается по мере возможности. Поддерживаемые версии и приоритет конкретного отчёта определяются при разборе. Информация о внешних зависимостях может потребовать отдельного обращения к их разработчикам.

Обычные ошибки без чувствительных деталей и запросы функций следует создавать через [Issues](https://github.com/saymer-alt/link-generators/issues/new/choose).
